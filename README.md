# ربات فوروارد خودکار ایتا به تلگرام و روبیکا

این اسکریپت پایتون به صورت خودکار پیام‌ها (شامل متن، عکس و ویدیو) را از یک کانال عمومی در ایتا استخراج کرده و به کانال‌های تلگرام و روبیکای شما فوروارد می‌کند. این برنامه کاملا ماژولار، شی‌گرا و ناهمگام (Async) طراحی شده است تا بهترین عملکرد را داشته باشد.

## پیش‌نیازها و نصب

ابتدا مطمئن شوید که پایتون ۳.۸ یا بالاتر روی سیستم شما نصب است.
سپس با استفاده از دستور زیر در ترمینال، کتابخانه‌های مورد نیاز را نصب کنید:

```bash
pip install -r requirements.txt
```

کتابخانه‌های نصب شده شامل موارد زیر هستند:
- `requests`: برای ارسال درخواست‌های HTTP به وبسایت ایتا و API تلگرام.
- `beautifulsoup4`: برای استخراج اطلاعات از صفحه وب ایتا.
- `rubpy`: برای ارتباط با سرورهای روبیکا به صورت غیررسمی (MTProto).

## تنظیمات اولیه (Configuration)

پیش از اجرای اسکریپت، فایل `main.py` را با یک ویرایشگر متن (مثل VSCode یا Notepad) باز کرده و متغیرهای سراسری زیر را در ابتدای فایل با اطلاعات خود جایگزین کنید:

- `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام خود را که از `@BotFather` دریافت کرده‌اید قرار دهید. (ربات باید حتما ادمین کانال تلگرام باشد).
- `TELEGRAM_CHANNEL_ID`: آیدی کانال تلگرامی شما (مثال: `@my_channel`).
- `RUBIKA_CHANNEL_GUID`: شناسه `GUID` کانال روبیکای شما. (برای به دست آوردن آن می‌توانید از ربات‌ها یا روش‌های دریافت GUID در پایتون استفاده کنید. ربات شما/اکانت شما باید ادمین کانال روبیکا باشد).
- `EITAA_CHANNEL_ID`: آیدی کانال ایتا بدون `@` (مثال: `varzesh3`).
- `CHECK_INTERVAL_MINUTES`: بازه زمانی (به دقیقه) برای بررسی کانال ایتا (پیش‌فرض ۵ دقیقه).

## نحوه اجرا

برای اجرای ربات، دستور زیر را در ترمینال یا CMD وارد کنید:

```bash
python main.py
```

### لاگین در روبیکا (فقط برای اجرای اول)
کتابخانه `rubpy` از طریق اکانت اصلی روبیکا متصل می‌شود. **در اولین اجرای برنامه**، اسکریپت از شما شماره تلفن اکانت روبیکاتان را می‌خواهد. سپس یک کد تایید (پیامک یا در اپلیکیشن روبیکا) برای شما ارسال می‌شود که باید آن را در ترمینال وارد کنید.
پس از لاگین موفق، یک فایل نشست (Session) به نام `rubika_session.sqlite` در کنار فایل ساخته می‌شود و در دفعات بعدی اجرای اسکریپت نیازی به لاگین مجدد نخواهد بود.

## ساختار وضعیت (State)
برنامه به صورت خودکار یک فایل به نام `last_post.txt` در کنار خود می‌سازد و آیدی آخرین پیامی که فوروارد کرده است را در آن ذخیره می‌کند. در صورت قطعی اینترنت یا خاموش شدن سیستم، دفعه بعدی که برنامه را اجرا کنید، بررسی را دقیقاً از آخرین پست موفقیت‌آمیز ادامه می‌دهد و پیام تکراری نمی‌فرستد.

## مدیریت خطاهای رایج (Troubleshooting)

- **ارور Timeout در دریافت اطلاعات:** اگر با خطای Timeout از سوی ایتا مواجه شدید، به دلیل کندی شبکه یا محدودیت آی‌پی است. برنامه در برابر این خطاها مقاوم است و صرفاً در دور بعدی مجدداً تلاش می‌کند.
- **ارورهای Rubpy (مانند `AuthKeyUnregistered`):** به این معناست که نشست روبیکای شما باطل شده است. فایل `rubika_session.sqlite` را به صورت دستی پاک کنید و یکبار دیگر برنامه را اجرا کنید تا از شما شماره بخواهد.
- **فرمت‌های غیرمجاز تلگرام/روبیکا:** برنامه قابلیت تشخیص پسوندهای رایج مانند `mp4` و `jpg` را دارد و در صورتی که فایلی حجم خیلی بالا (بیش از ۵۰ مگابایت برای تلگرام) داشته باشد، ممکن است با خطای آپلود مواجه شوید.
- **مسدود شدن توسط ایتا:** در صورتی که فاصله زمانی چک کردن (CHECK_INTERVAL_MINUTES) را خیلی کم کنید (مثلا چند ثانیه)، ایتا ممکن است آی‌پی شما را موقتاً محدود کند. پیشنهاد می‌شود روی همان ۵ دقیقه یا بیشتر تنظیم شود.

## سایر نکات
- برای خاموش کردن ربات می‌توانید کلید ترکیبی `Ctrl + C` را در ترمینال فشار دهید.
- فایل‌های مدیای دانلود شده از ایتا با نام `temp_media.*` روی سیستم ذخیره و پس از آپلود موفقیت‌آمیز بلافاصله از هارد شما حذف می‌شوند (پاک‌سازی خودکار).
